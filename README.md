# REUSE – Smart Reuse & Recycling Management System (IMS)

## Project Structure
```
REUSE-IMS/
│
├── main.py                     # Python Flask backend server & routes
├── requirements.txt             # Dependencies (Flask, Werkzeug)
├── run.bat                      # Windows one-click startup batch script
│
├── templates/                   # Jinja2 HTML templates
│   ├── index.html               # Main dashboard with 5 stat cards & charts
│   ├── login.html               # Authentication login page
│   ├── register.html            # User registration page
│   ├── products.html            # Browse catalog with category pills & filters
│   └── add_product.html         # Product listing form with image upload
│
└── static/                      # Static assets
    ├── style.css                # Clean, eco-friendly green/white theme CSS
    ├── script.js                # Frontend charts (Chart.js), modals, & filters
    └── images/                  # Stored product uploads and images
```

## How to Run

1. Open your terminal in the `REUSE-IMS` folder:
   ```bash
   cd REUSE-IMS
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:
   ```bash
   python main.py
   ```

4. Open your browser:
   ```
   http://127.0.0.1:5000
   ```
